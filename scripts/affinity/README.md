## ⛔ 이 축의 핵심 셋

```
① Affinity 는 «밖에서 몰린다» — 앱 내장 MCP(localhost:6767·SSE). 화면 클릭이 «필요 없다»
② 다만 ***앱이 떠 있어야 한다*** ⇒ 레지스트리에서 drive: 'app-attached'
③ 그래서 「못 쟀다」가 «실패와 다른 종단»이다 — 무인 런은 그것을 구별해야 한다
```
