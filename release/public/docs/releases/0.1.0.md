# 0.1.0

> Released under the previous name **monad**. From 0.2.0 the project is **Elanous** (`elanous` command, `~/.elanous`). Commands and paths below are as they were at the time.

First public release of monad.

- One-line install for macOS / Linux and Windows PowerShell; assets verified against `SHA256SUMS`.
- `monad self-update` and `monad doctor`.
- Trading execution is not part of the open-source core.
